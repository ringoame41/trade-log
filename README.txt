Trade Log Secure PWA

セキュリティ改善:
- ブラウザ内データをAES-256-GCMで暗号化して保存
- PBKDF2-SHA256（310,000回）でパスフレーズから鍵を導出
- 暗号化バックアップの出力・別端末での復元
- 取引データを外部サーバーへ送信しない設計

スマホとPCでの使い方:
1. このフォルダの全ファイルをHTTPS対応の静的ホスティングへ配置
2. スマホとPCの両方で同じ公開URLを開く
3. 各端末で同じパスフレーズを設定（または復元時に入力）
4. 片方で「暗号化バックアップ」を出力し、安全な方法で他方へ移す
5. 受け取った端末で「バックアップを復元」を選ぶ

重要:
- 自動同期ではありません。端末間の更新を反映するには、都度バックアップ・復元が必要です。
- 復元すると復元先端末の既存データを置き換えます。必要なら先にバックアップしてください。
- パスフレーズを忘れると復元できません。安全なパスワード管理ツール等に保管してください。
- 暗号化バックアップファイルも大切に保管してください。
- CSVの平文出力機能は削除しています。必要な場合は暗号化バックアップを使ってください。
- PWAのインストールとWeb CryptoにはHTTPSが必要です（localhostを除く）。
- 本アプリの暗号化はブラウザ内で実行されます。端末自体がマルウェア感染・侵害されている場合や、公開ホスティング先の配信ファイルが改ざんされた場合まで防げるものではありません。
